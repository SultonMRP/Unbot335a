# UnBot 3.3.5a

WotLK 3.3.5a player-bot controller (UnBot) plus its **YssBossLoot** dependency.

## Install

Unzip `unBot-3.3.5a_1.2.zip` into `Interface\AddOns` so you have:

- `Interface\AddOns\UnBot`
- `Interface\AddOns\YssBossLoot`

## 1.2

- Item-bag **?** query for unknown items (whisper `c` links)
- Main bar lock: `/ub lock` or `/unbotlock`
- UnBot frames use `MEDIUM` strata so they sit above ButtonForge bars
